# Leave Me Alone

A Chrome extension that answers the questions every website asks, so you don't
have to. Necessary cookies only, no notification prompts, no location
requests, no newsletter popups — on every site, automatically.

- [Privacy policy](privacy.md)
- [Source on GitHub](https://github.com/IconoclasticGoat/leave-me-alone) (MIT)

## What it does

Turn on the switches you want. From then on, every site you visit gets that
answer before it asks.

**On by default:** reject cookie banners · block notification prompts · block
location requests · dismiss newsletter popups · send Global Privacy Control ·
block popups & automatic downloads · block camera & microphone prompts

**Off by default:** mute all sites · hide chat bubbles · block Google one-tap
sign-in · delete all cookies on quit

## Honest about the limits

Cookie banners are an arms race. The extension handles the major consent
platforms and falls back to hiding banners it doesn't recognise, but a site
can always do something new. Blocking prompts is different: that runs through
Chrome's own permission settings, so it is not a heuristic and does not miss.

One site giving you trouble? Pause the extension there from the toolbar.
Everything goes back to normal on that site and stays as you set it
everywhere else.
